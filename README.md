# Подготовка к запуску:
1. Запустить PostgreSQL. Создать в ней новую БД.
2. В БД создать таблицу таким скриптом:
```sql
create table "PrefixString"
(
	pref_str bytea primary key,
	count integer not null check (count > 0)
);
```
3. Скопировать данный репозиторий.
4. Создать файл ".env" в папке, в которой оказался файл "main.py", и указать в нём следующие параметры:
```env
POSTGRES_DRIVER=psycopg
POSTGRES_DB=<название базы данных>
POSTGRES_USER=<имя пользователя, которое указали для БД>
POSTGRES_PASSWORD=<пароль, который указали для БД>
PORT_DB=<порт, по которому работает запущенная СУБД (обычно это 5432)>
POSTGRES_IP=127.0.0.1
```
5. Положите ваш корпус текстов в папку, лежащую рядом (не внутри!) с папкой скопированного репозитория.
Файл должен называться "corpus.csv" и иметь такую структуру:
```
page_id,title,url,lang,chars,text
<номер страницы>,<заголовок>,<url>,<язык>,<число символов в text>,"<текст, используемый программой>"
<номер страницы>,<заголовок>,<url>,<язык>,<число символов в text>,"<текст, используемый программой>"
<номер страницы>,<заголовок>,<url>,<язык>,<число символов в text>,"<текст, используемый программой>"
<номер страницы>,<заголовок>,<url>,<язык>,<число символов в text>,"<текст, используемый программой>"
...
```
6. Запустите терминал Линукс/git bash (можно попробовать и powershell, но для неё не факт, что сработает),
зайдите в ней в папку, в которой лежит main.py (проще говоря, в ту папку, внутри которой команда
```bash
ls
```
выдаст список файлов репозитория, включая main.py).

7. Создайте виртуальное окружение командой
```bash
python -m venv venv
```
для Windows или
```bash
python3 -m venv venv
```
для Linux.

8. Войдите в окружение командой
```bash
source venv/Scripts/activate
```
для Windows или
```bash
source venv/bin/activate
```
для Linux.

9. Выполните установку нужных библиотек командой
```
pip install -r requirements.txt
```
# Запуск:
Находясь в виртуальном окружении, выполните
```bash
python main.py
```
